# @turystack/react-web

TuryStack React web component library built with Base UI and shadcn patterns.

## Installation

```bash
pnpm add @turystack/react-web
```

### Peer dependencies

The host application provides these:

```bash
pnpm add @turystack/react-hooks @turystack/react-icons react react-dom tailwindcss
```

## Entry points

```ts
import { /* … */ } from '@turystack/react-web'
import { /* … */ } from '@turystack/react-web/hooks'
import { /* … */ } from '@turystack/react-web/styles.css'
```
